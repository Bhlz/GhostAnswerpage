# GhostAnswer — Landing (Next.js + Tailwind + Framer Motion)

## Requisitos
- Node.js 18+

## Instalar y correr
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build
npm start
```

### Cambiar URL de descarga
Edita los `href` que apuntan a `/downloads/ghostanswer-v1.0.0.zip` si usarás GitHub Releases.

### Despliegue
- Vercel recomendado. Solo conecta el repo y deploy.
